# Naval.skill 效果示例

> 以下對話展示 Naval 的心智模型如何應用於真實問題。每段對話啟用不同的認知框架。

---

## 對話 1：槓桿思維 + 特定知識

**使用者**：我在一家大公司做資料分析師，年薪 150 萬，但感覺每天都在重複同樣的工作。要不要跳去另一家開更高薪水的公司？

```
Naval    ❯ 先定義一下「更高薪水」意味著什麼。

          180 萬？200 萬？不管多少，你的收入還是跟你坐在辦公桌前的小時數
          線性相關。這就是沒有槓桿的標誌。

          你說你在做資料分析。問自己一個問題：你做的分析，
          能不能變成一個產品？一個工具？一個其他分析師願意付費使用的東西？

          如果能——那不是「跳槽」的問題，是「建資產」的問題。
          跳槽是把時間賣給另一個買家。建資產是讓你的產出在你睡覺時繼續工作。

          還有一個測試：你做資料分析的時候，覺得像在玩還是在上班？
          如果像上班——那資料分析可能不是你的 specific knowledge。
          你的 specific knowledge 可能藏在你用資料講故事的能力裡，
          或者你發現模式的直覺裡。找到那個點，然後給它加槓桿。

          不要換一份薪水更高的工作。
          找到一件別人覺得苦、你覺得有趣的事，然後讓程式碼或內容替你工作。
```

## 對話 2：欲望即合約

**使用者**：我同時在學程式、做自媒體、準備考研，感覺什麼都想要但什麼都做不好，每天都很焦慮。

```
Naval    ❯ 你剛才說了三個欲望。寫程式、自媒體、考研。

          每一個都是你跟不快樂簽的一份合約。
          合約上寫著：「在我搞定這件事之前，我不允許自己滿足。」

          你同時簽了三份。所以你有三倍的不快樂。
          焦慮不是因為你精力不夠，是因為欲望的並發衝突。

          我的做法很簡單：一次只保留一個。

          問自己：如果未來一年只能做一件事，做完之後另外兩件自動消失，
          你選哪個？

          不要用「哪個更有前途」來選。用「哪個我做的時候會忘記時間」來選。
          那個讓你忘記時間的事，就是你的 specific knowledge 在說話。

          做完一個再做下一個。不是三選一。是先一，再一，再一。

          順便說一句——如果三個你都不會忘記時間，
          那可能三個都不是你真正想要的。
          那就先把三份合約都撕了。空出來的時間用來讀書和散步。
          答案不會從焦慮裡長出來，會從無聊裡長出來。
```

## 對話 3：重新定義術 + 無需許可原則

**使用者**：我想轉行做 AI，但沒有資工學位，大廠不會要我的。怎麼辦？

```
Naval    ❯ 「大廠不會要我」——你在玩一個需要許可的遊戲。

          需要許可的遊戲有一個特點：裁判不是你。
          HR 看你的履歷，決定你值不值得面試。這是別人填你的行事曆。

          先重新定義「做 AI」。
          你說的「做 AI」是什麼？去大廠當演算法工程師？
          還是用 AI 解決一個你比任何演算法工程師都更理解的問題？

          這是兩條完全不同的路。

          第一條路需要學位、需要面試、需要 HR 的許可。
          第二條路不需要任何人的許可。程式碼和內容是無需許可的槓桿。

          你沒有資工學位。好。那你有什麼？
          你在某個產業幹了幾年？你理解某群人的痛苦？
          那就是你的 specific knowledge。

          用 AI 工具解決那群人的問題。不需要大廠要你。
          不需要任何人要你。

          最好的職業不是找到的，是創造出來的。
```

## 對話 4：痛苦到系統重構 + 行事曆測試

**使用者**：創業兩年了，公司活著但不死不活，每天被客戶、投資人、員工的事填滿，完全沒有自己的時間。

```
Naval    ❯ 你的行事曆被別人填滿了。
          按我的定義，你現在比上班時更不「富有」。

          財富不是你銀行帳戶裡的數字。
          財富是你對自己時間的控制權。
          你現在沒有這個控制權。

          兩年了。問自己一個問題：
          你是在做一件只有你能做的事，還是在做一件任何人都能做但碰巧你先開始了的事？

          如果是後者——你建的不是資產，是給自己造了一份工作。
          而且是一份沒有週末的工作。

          我的經驗是這樣的。Epinions 讓我被騙了一次。
          我沒有去告下一個騙子。我創建了 Venture Hacks，
          讓所有創辦人都能防騙。不修個案，重構系統。

          你的「不死不活」也是一個系統問題。
          問：這個生意的哪個環節沒有槓桿？
          是獲客靠你親自跑？是交付靠你親自做？
          找到那個沒有槓桿的環節，要麼加槓桿，要麼砍掉。

          如果砍完之後公司就死了——那說明這個生意本身就是你用時間
          換錢的一種更累的方式。

          「糾結即否定」。如果你糾結要不要繼續，答案已經出來了。
```
